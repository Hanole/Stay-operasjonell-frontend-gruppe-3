# operasjonell-frontend-gruppe-3<br>
Operasjonell Frontend - Arbeidskrav 1, 2 og 3 - Gruppe 3
<br><br>
Stay er en tjeneste som skal gjøre det enklere for brukere å finne og booke rom hos Bed & Breakfast-steder. Løsningen lar brukeren registrere seg, logge inn, utforske rom, lese og skrive anmeldelser, samt opprette og administrere egne bookinger.
<br><br>
Løsningen bruker et eksisterende API med ressursene USERS, ROOMS og BOOKING. Full CRUD (opprette, lese, oppdatere og slette data) er implementert mot disse ressursene i tråd med kravspesifikasjonen.
<br><br>
## HVORDAN KJØRE PROSJEKTET:
Dette prosjektet bruker en egenmodifisert Crudops som API: [https://github.com/hanole/crudops]

### 1. Klon og start opp Crudops
```
git clone https://github.com/hanole/crudops.git
cd crudops
npm install
npm start
```

Backend kjører lokalt på http://localhost:3000

### 2. Start prosjektet
Kjør prosjektet i en egen terminal etter at Crudops har startet.
```
git clone https://github.com/Hanole/Stay-operasjonell-frontend-gruppe-3
cd Stay-operasjonell-fronted-gruppe-3
npm install
npm run dev
```
